# SkillBadi

Public website: https://cks-edu.github.io/ai-career-atlas-pages/

**Choose, learn, build and grow.** A static learning library for Software and AI Engineering.

Eleven courses are available: Frontend, Full-stack, Backend, Java, Python, DevOps, GenAI application engineering, Agent Engineering, RAG/Retrieval Engineering, MLOps and AI Evaluation. The remaining 123 catalogue courses retain their guides and saved work as Coming soon previews. The full library has 134 courses, 402 levels and 994 lessons.

This release adds 36 original AI lessons across four courses and three levels, with teaching, mental models, runnable Python examples, practical tasks, expected results, failure cases, persona guidance and quizzes. All 958 previous lesson payloads and IDs remain exact. All 126 downloaded core reference examples were executed. Optional LangGraph 1.2.18 and MLflow 3.17.2 scripts were tested separately; real cloud/GPU deployments and model inference were not executed.

Weekly progress leads with evidence counts, current study priorities and weak areas. Planning, recovery, Calendar settings and history expand on demand. Mobile filters are compact. Fonts and existing palette remain; field-specific software and AI marks identify the course.

Progress and notes stay local. Calendar identities and backup formats are preserved. Automatic Google updates require the existing OAuth configuration and consent. Manual Calendar drafts/downloads remain snapshots.

The authored tutor has 12,209 cards. Optional on-device Qwen selects known lesson IDs; model-generated prose, commands, links and scores are not displayed as verified answers. No inference-server or token bill is required, but optional model files and device resources are used.

Audit: 261 public source URLs checked; 258 responded and three official vendor pages blocked automated access. Two outdated links were corrected. HTTP success is not factual validation. Desktop/mobile flows and automated regressions passed locally.
