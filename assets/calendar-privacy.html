Your optional Google Calendar connection

Updated 26 October 2026. Career Atlas is a static learning website. Google authorization is optional and separate from your browser-local learner profile.

What is sent to Google

For scheduled tutor reviews, we send the course and topic title, activity instructions, dates, time zone, reminder preference, and public lesson and Focus links. Private event properties hold an app marker, a random connection identity and hashed review identifiers so rescheduling can update the same event.

Your nickname, quiz answers and scores, written interview responses, lesson notes and Focus logs are not included in events or calendar API requests.

Permission and account identity

The Google permission lets the app read and change events on calendars you own. The implementation uses your primary calendar and filters requests to events marked for this site and learner connection. It does not request your other calendar events or use calendar attendance to grade learning.

A separate OpenID permission returns a Google account identifier. We hash that identifier locally to avoid silently switching accounts. We do not request your email address or name. Google processes authorization and API requests under its own privacy policy.

Storage and security

The short-lived access token stays in this tab’s memory. It is never written to localStorage, IndexedDB, a backup file, a URL or an event. No token or learner record is sent to a Career Atlas server. There is no inference or calendar backend.

The random connection identity, hashed account identifier, connection preference and last completed sync time stay in localStorage. They are included in your explicit unified backup so the same learner connection can be restored on another device. Keep that backup private. Learning progress remains local; connecting Google does not transfer it between devices.

Updates, removal and disconnecting

After connection, saving or rescheduling the local review plan can update managed events while the website is open and access remains valid. Superseded future managed events are cancelled. Past event history and local learning evidence are retained. Errors leave changes pending for a retry; reconnect when access expires.

Disconnecting in this browser stops updates and clears the in-memory token. Existing Google events remain. You can remove those events in Google Calendar and revoke the app’s permission through Google account connections. Clear this website’s browser data to remove local connection records, and delete exported backups if you no longer want to retain them. Reconnecting after clearing data requires restoring the same backup to retain the same event identity.

Old manually imported or draft-created events cannot be safely recognized as managed events. Remove those old copies once before enabling automatic updates. Manual Google changes do not update the local planner.
